# Nonogram Studio

[English](README.en.md)

Nonogram Studio 是一个本地运行的数织（Nonogram / Picross）求解器，提供响应式 Web UI、线索校验、唯一解/多解反馈和逐格动画。

## 启动

Windows 用户双击 `start.bat` 即可。首次运行会创建 `.venv` 虚拟环境并自动打开浏览器。也可以在 PowerShell 中运行 `.\run.ps1`。默认地址为 <http://localhost:8000>。

项目仅依赖 Python 标准库，不需要下载第三方包。界面支持 1×1 到 120×120 网格，行列线索可用空格、英文逗号或中文逗号分隔，多位数字直接输入（例如 `10 2`）。

## 截图识别和自动填写

展开“截图识别与自动操作”，选择包含完整题目、行列线索和棋盘的 PNG/JPEG 截图（建议裁剪到题目区域，避免浏览器工具栏和页面其他大块内容），再点击“识别截图”；也可以直接按 Ctrl+V 粘贴剪贴板中的截图。程序会在浏览器本地寻找规则网格，读取行列数字，填入可编辑的线索框并尝试求解。支持白底黑线、粗细边框和多位数字（例如 13、16）的常见布局；识别结果带有置信度，低置信度时请先人工核对线索。

求解成功后可生成鼠标操作序列。勾选“同时用右键标记空格”会为确定的空格生成右键操作；填写 X/Y 偏移和缩放后，先点击“生成/执行点击”进行安全演练，确认题目页面和坐标无误，再同时勾选“我确认要操作当前屏幕上的 Nonogram 页面”和“我已核对识别线索和求解结果”。未勾选确认时不会移动鼠标。Windows 下使用系统鼠标事件，其他系统会保留脚本复制功能但不执行系统鼠标。

截图坐标是图片像素坐标：如果截图从屏幕 `(x, y)` 开始，填入对应 X/Y；当前屏幕棋盘尺寸与截图不一致时，按 `当前格子尺寸 ÷ 截图格子尺寸` 设置缩放。网页缩放、浏览器地址栏和 DPI 缩放可能造成偏移，建议先取消确认做 dry-run，并从少量操作开始。

## 多语言

界面默认简体中文，可通过右上角菜单切换为 English、日本語、한국어、Español、Français、Deutsch、Português、हिन्दी 或 Русский。选择会保存在浏览器中。源码和 HTTP 响应统一使用 UTF-8，便于显示非 ASCII 线索和翻译。

## 求解器和 GPU

求解器使用逐行/逐列候选排列、约束传播和最少候选优先搜索。它对这类离散约束问题采用 CPU 优化；GPU 通常不会改善候选筛选，且项目保持零第三方运行依赖。

## 验证

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

浏览器验收覆盖了上传附件、Ctrl+V 粘贴截图、25×25 网格检测、行列多位数字识别、自动求解、普通文本粘贴、英文切换、手机宽度布局和鼠标 dry-run。在线 Nonogram 页面上的棋盘结构也已用于验证常见的左键填充、右键标记语义；自动填写前仍需按当前页面实际坐标校准。

## 文件

- `app.py` — 标准库 HTTP 服务、求解 API 和 Windows 鼠标 API。
- `static/index.html` — 响应式页面和动画样式。
- `static/app.js` — 输入处理、API 调用、渲染和截图流程。
- `static/image.js` — 浏览器端网格检测、数字模板识别和坐标提取。
- `static/i18n.js` — 多语言文案。
- `start.bat` — Windows 一键启动脚本。
- `run.ps1` — PowerShell 启动脚本。
